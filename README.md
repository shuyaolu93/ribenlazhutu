# 日本蜡烛图技术 · K线形态图谱

基于《日本蜡烛图技术（第2版）》（史蒂夫·尼森 著）整理的 K 线技术形态图谱网站：**101 个技术形态，16 个分区**（第四~十七章 + 术语表 A/B）。每个形态配有示意 K 线图（内联 SVG）与书中真实案例，点击卡片可查看详情。界面采用「白岩 · 极简纸白」简洁风格。

## 在线网站

- 在线访问（doubao-html）：https://ocntfc8vk7ec.doubao.link/app/app_17gjjzujake

## 简洁版（本仓库）

本仓库即简洁版网页源码，数据外置拆分，浏览器直接打开 `index.html` 即可使用：

```
index.html             页面入口（结构 + 渲染逻辑）
assets/data1.js        数据：第四~五章（6 + 8 条）
assets/data2.js        数据：第六~七章（18 + 11 条）
assets/data3.js        数据：第八章~第十章（10 + 1 + 3 条）
assets/data4.js        数据：第十一~十七章（4 + 1 + 3 + 6 + 3 + 4 + 1 条）
assets/data5.js        数据：术语表 A（10 条）+ 术语表 B（12 条）
```

> 另有一份单文件自包含版（全部数据内联，一个 HTML 打开即用），与拆分版内容完全一致。
